# Changelog

## 0.6.3 - 2026-07-08

### Added

- Sphinx docs for installation, overview, package map, operator runbook,
  release notes, validation, troubleshooting, security/data handling, gateway
  capabilities, and API overview.
- Generated API documentation for public `mixle_mlops` modules and gateway
  routes.

### Changed

- Documentation now names gateway, registry, auth, RAG, multimodal, MCP,
  telemetry, pool jobs, feedback, drift, and deployment boundaries more
  explicitly.

### Fixed

- `docs/_build` is ignored for local builds.

### Removed

- Nothing removed for this documentation pass.

### Known limitations

- Public release still needs clean package build/install, route/service tests,
  external-service skip/mock/real status, and family co-install verification.
